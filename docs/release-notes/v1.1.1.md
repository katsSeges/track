Fixes the island's task timer after Claude Code compacts a conversation.

## Fixed
- **Compaction doesn't reset the timer to hours.** When Claude Code compacts a long conversation, it writes a summary stamped with the conversation's first time. Track read it as a new prompt, so the island showed e.g. 1:29:37 for a task that had run 40 seconds. Summaries no longer count as prompts.
- **Old lines never move a timer back.** For all three tools, a line from before the running task can no longer start, steer or end it.

## Install
Download `Track-1.1.1-win-x64.zip` below, unzip it and run `powershell -ExecutionPolicy Bypass -File scripts\install.ps1`. It replaces 1.1.0 and keeps your settings and data. No .NET installation needed.
