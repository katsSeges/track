Sub-agents in the island and the tray.

## New
- **Sub-agents under their agent.** When Claude Code, Codex or Copilot starts sub-agents, the opened island lists them under the agent that started them: name, task, model, tokens and a live run time. Nested sub-agents sit one step further in. A finished one shows a ✓ and its run time, dimmed, until its agent finishes.
- **Dots in the compact island.** One small pulsing dot per running sub-agent, after the timer.
- **Counted in the tray.** A running row reads "1 session · 2 sub-agents".
- **Background work keeps the agent.** If an agent's turn ends while its sub-agents still run, it stays in the island (its own timer stops) until the last one finishes.

## Fixed
- A Claude Code sub-agent no longer restarts its parent's task timer, and its finish no longer ends the parent's task.
- Codex sub-agents no longer show up as separate agents; they are listed under their parent.
- An agent's "this session" tokens now include its Codex sub-agents.

Checked against the tools' own figures: every Copilot sub-agent's run time and tokens match Copilot's own numbers exactly.

## Install
Download `Track-1.1.0-win-x64.zip` below, unzip it and run `powershell -ExecutionPolicy Bypass -File scripts\install.ps1`. It replaces the installed version and keeps your settings and data. No .NET installation needed.
