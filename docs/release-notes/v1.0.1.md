Fixes the island's task timer for GitHub Copilot, so it matches Copilot's own timer.

## Fixed
- **Steering doesn't restart the timer.** A message you type while Copilot is working (steering) now continues the running task instead of starting the timer from 0:00. Messages in the same Copilot interaction also continue it.
- **Sub-agents don't restart the timer.** Copilot writes its sub-agents' prompts into the same log; they now count as steps of the main task.
- **Waiting for your answer isn't working.** When Copilot asks you something (`ask_user`), it no longer counts as working (the tray mark turns grey), and the island shows **"Copilot needs you ?"** instead of "done ✓". Your answer starts the timer again, like a new prompt. Before, a long wait could leave the timer showing hours.

## Install
Download `Track-1.0.1-win-x64.zip` below, unzip it and run `powershell -ExecutionPolicy Bypass -File scripts\install.ps1`. It replaces 1.0.0 and keeps your settings and data. No .NET installation needed.
