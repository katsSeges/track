Track now comes with a Windows installer.

## New
- **Setup EXE.** Download `Track-1.2.0-win-x64-setup.exe` and run it. It installs just for you (no admin rights, no .NET needed), adds a Start menu shortcut and an entry in **Settings > Apps > Installed apps**, and can create a desktop shortcut.
- **Start with Windows** is a checkbox in Setup: on for a new install, and an upgrade keeps your current choice.
- **Safe upgrades and uninstall.** Setup asks you to close a running Track instead of killing it. Uninstalling keeps your settings and usage data.
- The ZIP is still there for script installs, with `scripts\install.ps1`.

Thanks to @oliverseges for the installer.

## Install
Download `Track-1.2.0-win-x64-setup.exe` below and run it. It replaces an earlier version (installed by Setup or by `scripts\install.ps1`) and keeps your settings and data. The installer isn't code-signed yet, so SmartScreen may warn: choose **More info > Run anyway**.
