# Track 1.2.0

## Added

- Provider support for Gemini CLI, OpenCode, Cline and Roo Code, with local token parsing and automatic visibility
  for providers that have recent usage or live activity. Ollama can be enabled for local running/loaded-model status
  only; it has no token data.
- Settings window with System/Light/Dark themes, Acrylic/Mica/Mica Alt/Solid materials, custom accent/provider colors,
  per-provider visibility and chat-app overrides.
- Detailed Analytics window with 7/30/90-day and custom ranges, provider token/cost charts, model breakdown,
  cache-hit rate, session statistics, local-time activity heatmap, top sessions and CSV export.
- Click-to-open provider chat targets, an optional global popover hotkey, agent-event notifications, and configurable
  day/month spend and token budget alerts.

## Windows installer

- **Setup EXE.** Download `Track-1.2.0-win-x64-setup.exe` and run it. It installs per-user without admin rights or a
  separate .NET install, adds a Start menu shortcut and an entry in **Settings > Apps > Installed apps**, and can
  create a desktop shortcut.
- **Start with Windows** is on for a new install; upgrades preserve the existing choice.
- **Safe upgrades and uninstall.** Setup asks you to close a running Track instead of killing it. Uninstalling keeps
  settings and usage data.
- The ZIP remains available for script installs via `scripts\install.ps1`.
- Thanks to @oliverseges for the installer.

## Install

Download `Track-1.2.0-win-x64-setup.exe` from Releases and run it. It replaces an earlier Setup or script install and
keeps settings and data. The installer is not code-signed yet, so SmartScreen may warn: choose **More info > Run anyway**.

## Privacy and limitations

- Provider usage remains local. Cost estimates use the public LiteLLM price list; an Ollama status check is made only
  to `127.0.0.1:11434` and only when Ollama is enabled.
- Notifications are disabled by default; the Behavior setting disables both agent-event and budget notifications
  and persists across restarts.
- Analytics is limited to 90 days. Session totals and first-to-last observed spans are full-session values for sessions
  whose observed interval overlaps the selected range; span is not active duration. Historical per-session rows
  already pruned by Track 1.1 cannot be reconstructed.
- Provider parsers use source-shaped fixtures; real provider logs were not available on the implementation host.
- Rendered images are illustrative and use a solid backdrop fallback. They do not prove native Acrylic/Mica behavior;
  that requires observation on a supported Windows build.
