Track now follows more agents, has a Settings window and a detailed Analytics view.

## New
- **More providers.** Gemini CLI, OpenCode, Cline and Roo Code usage is read from their local logs. Ollama can show its running and loaded models (it has no token data). Each provider is **Auto**, **On** or **Off**: Auto shows it while it runs or once it has recent usage, and Off stops reading its logs.
- **Settings.** Theme (System, Light or Dark), start with Windows, notifications, a keyboard shortcut for the popover, provider colors for light and dark, and which app opens when you click a provider.
- **Analytics.** 7, 30 or 90 days or a custom range: tokens and estimated cost per day by provider, models, top sessions, cache hits, your busiest hours and a CSV export.
- **Budget alerts.** Set a spend or token limit per day or month, in total or per provider. You get one notification per limit per period.

Thanks to @oliverseges for the providers, Settings, Analytics and alerts.

## Install
Download `Track-1.3.0-win-x64-setup.exe` below and run it. It replaces an earlier version and keeps your settings and data. The installer isn't code-signed yet, so SmartScreen may warn: choose **More info > Run anyway**.

## Good to know
- Everything stays on your computer. The Ollama check only talks to `127.0.0.1:11434`, and only when Ollama is On.
- The new providers' log formats were built from their source code; tell us if a total looks wrong. Tasks from older Cline versions (3.x) with an OpenAI-compatible provider may count cached tokens twice.
- The keyboard shortcut is off until you turn it on in Settings.
- Analytics goes back up to 90 days. Per-session history from before 1.3.0 was only kept for 7 days.
