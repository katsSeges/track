First release of **Track**, a small Windows tray app that shows whether Claude Code, Codex or GitHub Copilot is working right now and how many tokens (with an estimated price) each used today, this week and this month. Everything is read from the agents' own log files on your machine; nothing is sent anywhere except a once-a-day download of the public LiteLLM price list.

## What's in it
- **Tray icon** with the Claude, Codex and Copilot marks: in color while working, grey when idle.
- **Popover** (left-click): what is running, then Today / Week / Month with tokens, `$price · in · out · cache`, highest usage first, and a per-model breakdown on hover.
- **Usage chart**: stacked bars per tool (per hour for Today, per day for Week and Month), the top value, and a comparison such as `+18 % vs last week at this time`. Hover a bar for details; click it to see just that hour or day. The − button minimizes the chart.
- **Top island**: appears while an agent works (logo, waveform, timer, session tokens). Opened, it has a **Now** tab (running agents) and a **Usage** tab (the same chart and rows as the popover). Minimize it while agents keep running; the top edge brings it back.
- The week resets Monday 00:00, the month on the 1st, in your local time.

## Install
1. Download `Track-1.0.0-win-x64.zip` below (optionally check it against the `.sha256` file).
2. Unzip it and run `powershell -ExecutionPolicy Bypass -File scripts\install.ps1` in the unzipped folder.

Track is copied to `%LOCALAPPDATA%\Programs\Track`, starts with Windows (turn that off in the tray menu) and starts now. No .NET installation is needed. To remove it: `scripts\uninstall.ps1`.

Windows 10/11, x64. The app is not code-signed, so Windows SmartScreen may ask before the first start.
